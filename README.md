# CMObsTool

Windows x64 安装包与签名更新发布。

[下载最新版本](https://github.com/wangleiphnh/cmobstool-releases/releases/latest)

[查看各版本更新日志](CHANGELOG.md)

安装后可点击版本号检查更新。首次升级到支持自动更新的版本，需要手动安装一次；后续版本可在软件内更新。

安装更新前请保存方案、停止任务，并彻底退出其他实例。安装包公开下载，软件使用需要有效卡密。

本仓库仅提供安装包、版本说明和签名更新清单，不包含项目源码。随安装包提供的第三方许可见安装目录内资源文件。

`CHANGELOG.md` 自动汇总正式 Release 的版本号、发布时间和更新说明。发布新版本或编辑 Release 说明后，GitHub Actions 会自动同步；草稿和预发布版本不计入正式历史。也可在 Actions 中手动运行 `Update release changelog` 补齐记录，无需重新构建安装包。
